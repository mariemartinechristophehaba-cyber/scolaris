# Projet billetterie (en pause)

Application de billetterie et d'événements pour la Guinée : concerts, soirées, sport, culture, cotisations.
Projet mis en pause le 27/11/2026 pour se concentrer sur Scolaris et FixPro.

## Maquettes (dossier `maquettes/`)
- `simple-r1.png`, `simple-r2.png` : **style retenu**, simple et propre comme une boutique (accueil, événement, paiement, billet, cotisations, créer).
- `billetterie-r1.png`, `-r2.png`, `-r3.png` : écrans fonctionnels (création d'événement, achat, billet QR, scan à l'entrée, tableau de bord, ambassadeurs, accueil, page événement, vente au kiosque).
- `premium-r1.png`, `-r2.png` : version sombre (non retenue).
- Les fichiers `.html` sont les sources des maquettes.

## Idées clés
- Cible : petits et moyens organisateurs (soirées, boîtes, tournois, galas d'écoles), puis gros concerts.
- Paiement Orange Money / MTN + espèces dans des kiosques de quartier (points de vente agréés, commission).
- Ambassadeurs : lien personnel, 5 % par billet vendu.
- Sport : matchs, tribunes, pass saison. Cotisations : mariage, baptême, solidarité, études.
- Scan des billets QR avec un simple téléphone, billets déjà utilisés refusés.

## Concurrence
- Tikerama (Côte d'Ivoire, présent aussi en Guinée) : 10 % par billet vendu, 5 % sur les cotisations, frais de service possibles côté acheteur, lien personnalisé payant.
- Billetfacile (Guinée), Guichet (Maroc, annonce la Guinée).
- Proposition : 7 % tout compris pour l'organisateur, 0 frais pour l'acheteur, 5 % au lancement, cotisations 4 %.
